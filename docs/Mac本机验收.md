# HearNote：Mac 本机验收

目标是确认 App 在实际 Mac 上运行，并分别测量识别、翻译质量与延迟。已有 53 项 Core XCTest 通过和 Mac Swift parser 检查，仍不能替代 Apple SDK 编译、麦克风／系统音采集和本地模型推理。

使用合成材料或专门测试会议，不录入真实客户内容。记录 Mac 型号、芯片架构、macOS、Swift 版本、选定识别模型、Bedrock Region／模型，以及测试次数；报告不包含 API Key。

## 1. 构建和首次启动

按 [安装使用](安装使用.md) 克隆私有仓库。在根目录运行：

```bash
swift --version
bash scripts/build-mac.sh --open
```

预期核心测试、release 编译和签名验证通过，生成 `dist/HearNote.app` 并打开首次配置页。检查 `.app/Contents/Resources/` 中依赖 bundle 已复制；将 App 复制到 `/Applications` 再运行，确认不依赖原 `.build` 路径。

如有编译错误，保存复现步骤和最小修复，重跑失败检查。直接 `swift run` 不能代替带权限说明的 `.app` 验收。

## 2. 配置、权限与模型

| 检查 | 操作与通过标准 |
|---|---|
| Keychain | 用户在 App 填 Key；成功连接后退出重开，Key 不回显但能继续调用。偏好文件和导出不含 Key |
| Region／模型 | 使用有权限的两个模型和可用 Region；测试连接真实成功，切换与重开保存选择。完整型号按 README，不猜未核实 ID |
| 无 Key | 跳过配置后录音／本地转写可用；翻译与摘要提示配置，不丢录音 |
| API 错误 | 分别测试无效 Key、无权限模型和断网；出现清晰错误，界面可操作，不把不完整输出保存为成功。429 若遇到只记录限流，不制造持续付费重试 |
| 权限拒绝 | 分别拒绝麦克风、系统录制和单语 Speech；提示对应权限，无崩溃，已保存记录保留 |
| 模型准备 | 比较 Whisper Large v3 Turbo 与 Small；首次下载／预热单独计时，取消准备应可响应。缓存完成后重开，断网仅测本地转写 |
| 旧配置迁移 | 在独立测试配置验证旧内置型号迁移与自定义 Region／模型保留；删除候选后重开不重复加回。不要改用户现有配置做破坏性验证 |

系统录制权限名称随 macOS 版本变化，可显示为“屏幕录制”或“屏幕与系统音频录制”。系统音测试无需在 Zoom／飞书中开启屏幕共享；App 不保存屏幕图像。

## 3. 会议录音和实时翻译

先测试各来源 30–60 秒，再做连续会议：

| 场景 | 通过标准 |
|---|---|
| 麦克风 | 显示实时原文；开启翻译后有译文；结束保存可回听 |
| 系统声音 | 本机播放测试语音或会议另一端发言，本机麦克风关闭；系统音仍被捕获，标为会议声音 |
| 双源会议 | 戴耳机，Zoom／飞书两端交替发言；两端声音保留，字幕与回听时间戳对应 |
| 外放双源 | 记录回声／重复收音程度，不宣称已有回声消除 |
| 连续与静音 | 连录至少 3 分钟，中间静音 30 秒后继续；识别边界不明显漏句，后续字幕仍更新 |
| 长会议 | 条件允许测试 20–30 分钟；界面可操作，字幕不持续积压，内存无异常持续增长 |
| 极短语音与尾字 | 说“Yes／好”及含否定结尾的短句；立即结束，确认短音频与尾字保留或有明确超时提示 |
| 设备／退出 | 录音中切换耳机／麦克风不崩溃，异常明确；Cmd+Q 后重开，已录笔记与媒体保留 |
| 翻译开关 | 开始前关闭，录音中开启→关闭→开启；关闭期间录音／原文继续，旧请求不写回；恢复只翻译新稳定文字 |
| 修订保护 | 识别或手动修订原文，旧译文撤下；晚到译文不能覆盖新原文。仅时间戳变化不导致反复翻译 |

若本机模型跟不上实时或提示识别缓存积压，应记为实时性能未达标，即使录音已保存也不能记成全部通过。单语 Apple Speech 设备端不可用时，联网识别必须由用户明确选择。

## 4. 准确性与速度

两种本地识别模型各录一次以下合成材料：

> 预算是三百元，不是三千元。李明明天上午十点测试飞书会议。默认区域还没有决定。
>
> We have not agreed on the launch date. Keep the API timeout at 300 milliseconds.
>
> 这个 API 的 latency 不能超过 300 milliseconds，先不要上线。

逐项核对人名、产品名、时间、数字、单位、否定词和漏句。中文应译英文，英文应译中文；混合句须保留全部事实，均衡混合的中英两行均不得增删事实。再测试突然切换语言、两人交替及同时发言。

固定同一份原文，对有权限的候选模型各翻译至少 3 次。区分转写错误与翻译错误，不把“忠实于错误原文”当整体正确，也不凭少量主观样例声称准确率。

| 指标 | 测量方式 |
|---|---|
| 识别延迟 | 短句说完到原文出现 |
| 实时翻译延迟 | 短句说完到对应完整译文出现；同时观察连续发言是否积压 |
| 文字翻译耗时 | 点击提交到完整译文，固定相同输入与输出要求 |
| 连接测试耗时 | 设置页显示的网络与短生成总耗时；不等于纯 ping 或首字耗时 |
| 首次成本 | 模型下载／预热与首次调用单独记录，不混入后续中位数 |

记录每组次数、中位数与最慢值；在实际使用的 Mac 网络上比较 Region。Global profile 的入口 Region 不保证实际推理在该 Region。错误响应耗时不计为成功翻译速度。

## 5. 独立翻译

侧栏“翻译”或 `⌘⇧T` 打开，使用相同 Bedrock 配置：

1. 文字：测试中→英、英→中、混合与固定目标语种；纯译文无会议时间戳、摘要或解释。`⌘Return`、复制、朗读／停止和语言交换可用，键入时不发请求。

2. 取消与并发：请求中修改原文、目标语种、模型或 Region，清空、恢复历史、切走页面；旧结果不覆盖当前输入，也不进入历史。失败可手动重试，不能自动循环请求。

3. 语音：先准备模型，说完结束再翻译；中英混合、极短句、尾字均检查。切走页面或 Cmd+Q 释放麦克风。会议录音与翻译语音互斥；准备／监听／结束处理中，不能由设置或延迟目录回调替换正在使用的识别模型。

4. 对话：双方轮流点中文／英文按钮，逐轮语言方向与原文／译文正确。朗读后再开麦先停止朗读，不把自己的译文收成下一轮原文。

5. 图片：清晰中英截图先本地 OCR，校对后才翻译；无文字／损坏图片提示清晰，OCR 不让界面卡死。

6. 历史与收藏：成功译文可恢复／收藏；刚翻译或收藏后立即退出，重开应保留。仅在独立测试账户或备份副本测试历史损坏，异常持续提示新记录未保存，不覆盖损坏文件。

7. 分别测“语音结束→原文完成”“提交→完整译文”“图片导入→OCR 完成”，不能把文字翻译速度当语音端到端速度。

## 6. 听记整理与导出

- 导入 WAV／M4A／MP3 和带音轨 MP4，至少一份超过 3 分钟；损坏文件或无音轨视频清晰报错，不丢已有库。

- 点击时间戳回听，核对位置、暂停／继续与倍速。修改原文后旧翻译与摘要清空，重新生成对应新原文。

- 摘要区分决定与未决定，保留合成材料中的姓名、时间、300 元，不编造负责人或日期。

- 导出 TXT、SRT、Markdown、JSON，打开核对中文、顺序、时间戳和字幕换行；使用字幕工具加载 SRT。新建、搜索、收藏与重开均检查。

## 7. 结果与 GitHub 同步

结果注明通过、失败、未测；每个失败给复现步骤、实际结果、错误与最小修复。报告可保存为本机 `Mac本机测试结果.md`，包含 App 的实际绝对路径、测试配置、合成材料错误和速度表。截图隐藏凭据；录音、Key、用户笔记和本机日志不提交到 GitHub。

修复后按 [AGENTS.md](../AGENTS.md) 执行相关检查，审查 diff，再 commit／push 到当前 private 仓库；核对远端提交与本机一致。推送失败明确报告。

核心验收通过后运行：

```bash
bash scripts/package-mac.sh
```

挂载 `dist/HearNote.dmg`，检查 App 与 Applications 快捷方式，从安装后的 App 再启动。交付 `.app`／`.dmg` 本机绝对路径；只有真正构建并跑过核心功能，才标为“Mac 实机验证完成”。
