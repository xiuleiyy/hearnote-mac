# 听译：Mac 本机验收

目标是确认 App 在实际 Mac 上运行，并分别测量识别、翻译质量与延迟。Core 测试与 CI 构建、启动检查不能替代麦克风／系统音采集、本地模型推理和 GUI 功能验收。

使用合成材料或专门测试会议，不录入真实客户内容。记录 Mac 型号、芯片架构、macOS、Swift 版本、选定识别模型、Bedrock Region／模型，以及测试次数；报告不包含 API Key。

北京 Mac 当前负责安装与实机验收；程序 Bug 记录复现和证据，交回开发环境修复。本机代理本轮不自行修改程序逻辑或推送源码。

## 1. 构建和首次启动

日常验收优先按 [安装使用](安装使用.md) 下载已成功构建的 arm64 App／DMG。核对 SHA-256、源码提交和构建说明，将 App 安装到 Applications 后启动；无需每次重新配置 Xcode。

需要验证源码构建时，先安装并初始化完整 Xcode，再克隆私有仓库，在根目录运行：

```bash
swift --version
bash scripts/build-mac.sh --open
```

预期核心测试、release 编译和签名验证通过，生成 `dist/听译.app` 并打开首次配置页。将 App 复制到 `/Applications` 再运行，确认不依赖原 `.build` 路径。

图标验收：`Contents/Info.plist` 的 `CFBundleIconFile` 为 `HearNote.icns`，对应文件在 `Contents/Resources/` 中。安装后检查 Finder、Dock 与 `⌘Tab` 显示蓝青色声波笔记图标。更新已有 App 时先退出旧版本，再替换 Applications 中的 App；Dock 如果还显示旧图标，移除旧快捷方式并从 Applications 重新拖入，不清除用户笔记、设置或 Keychain。

名称验收：安装的 App 为 `听译.app`，窗口、侧栏顶部品牌、Finder、Dock 与权限提示显示“听译”，第一个侧栏导航显示“听见”。从新版打开已有笔记，核对原有录音、偏好和已配置 Key 仍可使用；不要删除数据或重置权限来模拟升级成功。

如有编译错误，保存复现步骤和最小修复，重跑失败检查。直接 `swift run` 不能代替带权限说明的 `.app` 验收。

## 2. 配置、权限与模型

| 检查 | 操作与通过标准 |
|---|---|
| Keychain | 用户在 App 填 Key；成功连接后退出重开，Key 不回显但能继续调用。偏好文件和导出不含 Key |
| Region／模型 | 使用有权限的两个模型和可用 Region；测试连接真实成功，切换与重开保存选择。完整型号按 README，不猜未核实 ID |
| 无 Key | 跳过配置后录音／本地转写可用；翻译与摘要提示配置，不丢录音 |
| API 错误 | 分别测试无效 Key、无权限模型和断网；出现清晰错误，界面可操作，不把不完整输出保存为成功。429 若遇到只记录限流，不制造持续付费重试 |
| 权限拒绝 | 分别拒绝麦克风、系统录制；旧 Apple 路径另测语音识别权限。错误明确，无崩溃。macOS 26 关闭 Siri／听写时，Apple 本地路径仍应识别；失败持续提示且录音可保存 |
| 模型准备 | 显示实际下载、预热、加载阶段和文件进度；没有模型时开始会议立即采音，准备期间可结束保存，回放包含准备期间声音；取消准备不停止录音，模型就绪后识别后续声音 |
| 识别语言 | English 固定英文，同一英文材料不应误出印地文；中英混合分别测纯英、纯中和交替，不应误选其他语言；会后重新转写也遵守所选语言 |
| 旧配置迁移 | 在独立测试配置验证旧内置型号迁移与自定义 Region／模型保留；删除候选后重开不重复加回。不要改用户现有配置做破坏性验证 |
| 会议默认语言 | 新安装和旧版首次升级均为 English／简体中文；之后手动改选会议语言或目标语言，未开始录音就退出重开也应保留。独立翻译页自己的语言设置不被覆盖 |

系统录制权限名称随 macOS 版本变化，可显示为“屏幕录制”或“屏幕与系统音频录制”。系统音测试无需在 Zoom／飞书中开启屏幕共享；App 不保存屏幕图像。

## 3. 会议录音和实时翻译

先测试各来源 30–60 秒，再做连续会议：

| 场景 | 通过标准 |
|---|---|
| 主窗口 | 开始和实时会议均嵌入主内容，没有录音模态窗口；可拖动标题栏、放大和缩小。最小窗口仍能操作开始／结束，长字幕正常换行 |
| 字幕空间与详情 | 正常录音时字幕紧接紧凑顶部；语言和状态在底部、详情默认收起。展开详情后可上下拖分隔线；缩到 900×600、拉高窗口、准备模型或出现长告警时，字幕与结束保存始终可达，长详情内部滚动 |
| 回看与布局切换 | 关闭跟随并滚到旧字幕，展开／收起详情、拖分隔线或缩放窗口，回看状态不重置；点击回到最新后才恢复跟随 |
| 切页和返回 | 录音中返回笔记、查看旧笔记、打开翻译页，再点“返回当前会议”或 ⌘⇧R；回到同一会议，计时继续，不重复录音，不取消识别／翻译 |
| 导入与保存导航 | 录音设置页导入文字或音视频成功后显示新笔记；取消导入仍留在原页。结束保存途中切页，保存完成仍回到该会议的“对照”页 |
| 麦克风 | 显示实时原文；开启翻译后有译文；结束保存可回听 |
| 外放麦克风排查 | 只选麦克风，分别暂停外放／开启外放说话；记下系统输入设备与输入电平、App 麦克风电平和回放。没有自己的人声应记采集失败；回放有人声而无文字应记识别失败，不以戴耳机当必要条件 |
| 系统声音 | 本机播放测试语音或会议另一端发言，本机麦克风关闭；系统音仍被捕获，标为会议声音 |
| 双源会议 | 戴耳机，Zoom／飞书两端交替发言；两端声音保留，字幕与回听时间戳对应 |
| 外放双源 | 按「外放回声消除」文档，复测仅远端、双方交替、双方同时讲话及静音恢复；同时检查字幕和保存回放，自己的发言不能丢失。记录残留重复和处理状态；合成测试通过不能替代真实外放验收 |
| 双源状态 | 其中一路无声音或无音频时，底部仍分别显示两路状态；不能把另一源正常当两路正常，折叠详情也能看到准备／失败摘要及取消准备 |
| 连续与静音 | 连录至少 3 分钟，中间静音 30 秒后继续；识别边界不明显漏句，后续字幕仍更新 |
| 长会议 | 条件允许测试 20–30 分钟；界面可操作，字幕不持续积压，内存无异常持续增长 |
| 极短语音与尾字 | 说“Yes／好”及含否定结尾的短句；立即结束，确认短音频与尾字保留或有明确超时提示 |
| 设备／退出 | 录音中切换耳机／麦克风不崩溃，异常明确；Cmd+Q 后重开，已录笔记与媒体保留 |
| 翻译开关 | 开始前关闭，录音中开启→关闭→开启；关闭期间录音／原文继续，旧请求不写回；恢复只翻译新稳定文字 |
| 修订保护 | 识别或手动修订原文，旧译文撤下；晚到译文不能覆盖新原文。仅时间戳变化不导致反复翻译 |
| 局部翻译失败 | 某段内容／双向校验失败时最多两次自动尝试，失败段有重试入口，后面的完整句仍翻译；失败提示不算译文。录音结束后当前最后一场仍可重试。错误测试使用 stub 或无费用的离线断网，不故意循环收费请求 |
| 请求故障恢复 | 鉴权／配置错误暂停并保留待处理段；修正后开启翻译或逐段重试。429、网络及服务错误有冷却和尝试上限；不把一次失败猜成凭据或限流故障 |
| 系统音收尾 | 启动中取消、连续点击结束／取消、正常结束均不重复停止或关闭文件；主动结束后的框架报错与录音中断区分。保存后音频完整可回放；真正写入／导出失败仍明确报错 |
| 上下字幕 | 每段原文在上、金色译文在下；共用时间戳和声音来源。中文／英文长短不同、译文晚到和双音源同一时间都不串段或错配；同一列表上下滚动 |
| Whisper 连贯句 | 连说超过 3 秒和跨 12 秒窗口的句子，原文在同一当前句增补；句末／明显停顿后形成句段再翻译，无重复前缀或窗口尾字丢失。中文夹英文、数字小数和常见缩写不因点号机械截断；无标点长发言仍有界分段 |
| 当前句与尾句 | 未完句显示“正在补全当前句…”，不能把每 1.2 秒无回调当说完；停录收尾保留最后未完句，关闭翻译仍只保存原文。麦克风和会议声音不被拼成同一句，取消／下一场不复活旧句 |
| 短句后的静音 | 播放带至少 0.8 秒真实尾静音的短测试音频后停止播放，分别测试不足及超过 2.5 秒的采集快照。系统不再送帧时仍能确认尾句，不能一直等待下次讲话；首轮错词允许原卡片修订。无真实尾静音时不能用等待时间代替停顿，也不无限重复解码同一快照 |
| 跟随与回看 | 默认跟随新增段、同段文字修订及译文返回；关闭“跟随最新”后停在回看位置，录音／识别／翻译继续；“回到最新”恢复跟随 |
| 对照保存 | 停止期间仍显示已有对照；保存后进入“对照”页，退出重开仍按片段对应。未完成或翻译关闭期间的段落显示“未翻译”，不会一直等待 |
| 翻译页 | 会议中已有逐段译文但尚无全文时，笔记“翻译”页显示当前有效译文和完成数量；陈旧译文不显示。保存的旧全文继续可读，缺段不能显示全部完成 |
| 全文操作 | 有原文且空闲时全文翻译／摘要可操作；会议开始、录音、保存和其他处理时显示具体原因。按钮与实际调用条件一致，结束／取消后恢复；不自动付费翻译 |
| 正文与按钮可读性 | 深浅主题下 Region／模型、全文动作和只读原文清晰；录音或处理锁定编辑时仍能选择复制正文，不将正文显示成禁用灰色；禁用按钮保留明确原因与下一步 |
| 旧笔记与校对 | 旧笔记正常打开；只有整篇译文时指引到“翻译”页，不猜对齐。修改原文后该段旧译文清除，改回旧文字也不恢复旧结果 |

若本机模型跟不上实时或提示识别缓存积压，应记为实时性能未达标，即使录音已保存也不能记成全部通过。macOS 26 新 Apple 路径失败不得暗中回退至 Siri 或联网识别；旧系统的联网识别必须由用户明确选择。新路径另按 [Apple 本地识别](Apple本地识别.md) 验证关闭 Siri／听写、资源准备与取消、双源和文件重新转写。

本次回归重点：系统声音回放可听但字幕为空时，记录持续识别告警与所选引擎；不重复把它认定为未录到音频。分别核对“系统声音已收到音频”的计时、识别就绪和原文出现。模型准备时结束、取消后重新开始、准备刚完成就结束、Cmd+Q 后重开，都不得晚到启动上一次识别或丢失原始音频。

## 4. 准确性与速度

用同一份音频与人工参考文本测试所选识别模型，不把不同声音材料或设置的结果算作模型对比。中文主要发言分别测试“普通话”和“中英混合”，全英文材料单独测试 English，记录实际加载型号。先验证以下合成材料：

> 预算是三百元，不是三千元。李明明天上午十点测试飞书会议。默认区域还没有决定。
>
> We have not agreed on the launch date. Keep the API timeout at 300 milliseconds.
>
> 这个 API 的 latency 不能超过 300 milliseconds，先不要上线。

逐项核对人名、产品名、时间、数字、单位、否定词和漏句。中文应译英文，英文应译中文；混合句须保留全部事实，均衡混合的中英两行均不得增删事实。再测试突然切换语言、两人交替及同时发言。

增加“东京只是测试区域，还没有决定默认区域”。“还没有决定”不能因分段变成设置指令。对“Feishu／飞书”和“Bedrock”等术语的识别错误单独记录；组句通过不代表错词已修复，非空译文数量也不是准确率。长发言的有界分段仍须检查是否拆开重要语义。

再用超过 10 秒的完整句测试“预算是 300 元，不是 3000 元”“Key 不能写进导出的文件”“while Li Ming finishes the test”。未完句应继续增补，检查否定／数字、谓语／宾语是否连贯。加静音段，确认没有独立“。”字幕。Whisper 的窗口保护不能补造从未识别的词，反复出现的错词与漏段仍记为 FAIL；详见 [实时字幕与失败恢复](实时字幕与失败恢复.md)。

固定同一份原文，对有权限的候选模型各翻译至少 3 次。区分转写错误与翻译错误，不把“忠实于错误原文”当整体正确，也不凭少量主观样例声称准确率。

| 指标 | 测量方式 |
|---|---|
| 识别延迟 | 短句说完到原文出现 |
| 实时翻译延迟 | 短句说完到对应完整译文出现；同时观察连续发言是否积压 |
| 文字翻译耗时 | 点击提交到完整译文，固定相同输入与输出要求 |
| 连接测试耗时 | 设置页显示的网络与短生成总耗时；不等于纯 ping 或首字耗时 |
| 首次成本 | 模型下载／预热与首次调用单独记录，不混入后续中位数 |

记录每组次数、中位数与最慢值；在实际使用的 Mac 网络上比较 Region。Global profile 的入口 Region 不保证实际推理在该 Region。错误响应耗时不计为成功翻译速度。

## 5. 独立翻译

侧栏“翻译”或 `⌘⇧T` 打开，使用相同 Bedrock 配置：

1. 文字：测试中→英、英→中、混合与固定目标语种；纯译文无会议时间戳、摘要或解释。`⌘Return`、复制、朗读／停止和语言交换可用，键入时不发请求。

2. 取消与并发：请求中修改原文、目标语种、模型或 Region，清空、恢复历史、切走页面；旧结果不覆盖当前输入，也不进入历史。失败可手动重试，不能自动循环请求。

3. 语音：先准备模型，说完结束再翻译；中英混合、极短句、尾字均检查。切走页面或 Cmd+Q 释放麦克风。会议录音与翻译语音互斥；准备／监听／结束处理中，不能由设置或延迟目录回调替换正在使用的识别模型。

4. 对话：双方轮流点中文／英文按钮，逐轮语言方向与原文／译文正确。朗读后再开麦先停止朗读，不把自己的译文收成下一轮原文。

5. 图片：清晰中英截图先本地 OCR，校对后才翻译；无文字／损坏图片提示清晰，OCR 不让界面卡死。

6. 历史与收藏：成功译文可恢复／收藏；刚翻译或收藏后立即退出，重开应保留。仅在独立测试账户或备份副本测试历史损坏，异常持续提示新记录未保存，不覆盖损坏文件。

7. 分别测“语音结束→原文完成”“提交→完整译文”“图片导入→OCR 完成”，不能把文字翻译速度当语音端到端速度。

## 6. 笔记整理与导出

- 导入 WAV／M4A／MP3 和带音轨 MP4，至少一份超过 3 分钟；损坏文件或无音轨视频清晰报错，不丢已有库。

- 原文非空的已保存笔记：点击“翻译全文”得到译文，取消进行中的全文翻译／转写后按钮恢复可用；旧全文与已有有效逐段译文仍可读。无原文但有录音时提供转写入口，转写前不提交空内容到模型。录音中查看笔记时全文按钮显示暂停原因和返回会议入口。

- 点击时间戳回听，核对位置、暂停／继续与倍速。修改原文后旧翻译与摘要清空，重新生成对应新原文。

- 摘要区分决定与未决定，保留合成材料中的姓名、时间、300 元，不编造负责人或日期。

- 导出 TXT、SRT、Markdown、JSON，打开核对中文、顺序、时间戳和字幕换行；使用字幕工具加载 SRT。新建、搜索、收藏与重开均检查。

- SRT 保存面板分别使用普通标题、含点标题和以 `.srt`／`.SRT` 结尾的标题，不应生成重复 `.srt.srt`。该项需在实际 AppKit 面板验证，导出内容正确不能代替文件名验收。

- 合成音频包含静音和正常语音时，新转写与四种导出不应出现 Whisper 技术占位 `[BLANK_AUDIO]`；英文词间空格、中文和时间戳仍完整。此修复只处理新识别输出，旧错误转写需要重新转写，人工输入的方括号或日志文字不应被导出器删除。

## 7. 结果与 GitHub 同步

