# 听记 App 图标

原创矢量设计：蓝青色圆角背景，白色笔记纸，声波与文字行。图案表示把声音记成文字；不含小字号文字，便于在 Dock 和 Finder 的小尺寸下辨认。

`HearNote.svg` 是可编辑源文件；`HearNote.iconset/` 包含从它生成的 10 张透明 PNG，覆盖普通与 Retina 尺寸。1024 × 1024 预览为 `HearNote.iconset/icon_512x512@2x.png`。

正常 Mac 构建直接使用已提交的 PNG，由系统 `iconutil` 生成 `Contents/Resources/HearNote.icns`，再签名 App。使用、安装与构建无需安装 Python 图像依赖。

修改 SVG 后，开发者可在源码根目录重新生成 PNG：

```bash
python3 -m venv .tooling/icon-design
.tooling/icon-design/bin/python -I -m pip install Pillow==11.3.0 CairoSVG==2.8.2
.tooling/icon-design/bin/python -I scripts/generate-icon.py
```

PNG 不包含个人路径、账号信息或图像 EXIF。构建验证检查图标声明、ICNS 解码、全部尺寸及 DMG 内的资源一致性；Finder、Dock 和切换应用中的实际显示仍需在本机确认。
